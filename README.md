# 💣 Игра «Сапёр» (Minesweeper)

Классическая игра «Сапёр», написанная на чистом **HTML, CSS и JavaScript**. 

## 🎮 Как играть
* **Левый клик мыши:** Открыть клетку.
* **Правый клик мыши:** Поставить или снять флажок 🚩.
* **Цель игры:** Открыть все пустые клетки и пометить все мины флажками, не подорвавшись на бомбе!

## 🚀 Особенности проекта
* Полностью одиночная разработка.
* Рекурсивный алгоритм автоматического открытия пустых зон.
* Оригинальная цветовая палитра для цифр.
* Полная поддержка флагов с блокировкой случайного нажатия на ячейку.
